│                                                                             │

│                                                                             │

│  bind = $mod SHIFT, 2, exec, kitty-session monitoring                       │
│                                                                             │

                               │

┌────────────────────────────────────────────────────────────────────────────┐
│               LAYER 2: PYTHON KITTENS (SESSION ORCHESTRATION)               │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Wrapper Script (~/.local/bin/kitty-session):                               │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │ python3 ~/.config/kitty/kittens/session-launcher.py monitoring      │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │

│  ┌──────────────────────────────────────────────────────────────────────┐  │

│  │   2. Parse 4 window definitions                                     │  │

│  │   2. Read ~/.ssh/config (auto-generated by agenix)                  │  │
│  │   3. Select correct per-device SSH key                              │  │
│  │   4. Build SSH command: ssh -i ~/.ssh/id_ed25519_laptop_intel ...   │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │ layout-parser.py                                                     │  │
│  │   1. Parse monitoring.toml (TOML format)                            │  │
│  │   2. Validate schema (required fields)                              │  │
│  │   3. Return structured layout object                                │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└──────────────────────────────┬─────────────────────────────────────────────┘

                               │

                               │

│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │

│  │                                                                      │  │
│  │ Performance: Async streaming, < 5s for 1 hour of logs               │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  ┌──────────────────────────────────────────────────────────────────────┐  │
│  │ db-tools                                                             │  │
│  │   - query: Execute read-only queries (or --write for mutations)     │  │
│  │   - replicas: Check replication lag                                 │  │
│  │   - admin: VACUUM, slow queries, table sizes                        │  │
│  │   - backup: Trigger database backups                                │  │
│  │                                                                      │  │
│  │ Performance: Direct PostgreSQL connection, < 500ms for simple query │  │
│  └──────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

## Data Flow: Session Launch

```
1. USER PRESSES HOTKEY
   Super+Shift+2
         │
         ▼
2. HYPRLAND EXECUTES COMMAND
   kitty-session monitoring
         │
         ▼
3. WRAPPER SCRIPT INVOKES PYTHON KITTEN
   python3 ~/.config/kitty/kittens/session-launcher.py monitoring
         │
         ▼
4. PYTHON READS LAYOUT CONFIG
   ~/.config/kitty/sessions/monitoring.toml

   [layout]
   name = "monitoring"

   [[windows]]
   title = "web-prod"
   ssh_target = "web-production"
   command = "htop"

   [[windows]]
   title = "api-prod"
   ssh_target = "api-production"
   command = "journalctl -u api.service -f"

   [[windows]]
   title = "db-prod"
   ssh_target = "db-production"
   command = "psql -U app production_db"

   [[windows]]
   title = "local-control"
   directory = "~/ops"
         │
         ▼
5. PYTHON RESOLVES SSH TARGETS
   ssh-manager.py reads ~/.ssh/config

   Host web-production
     HostName web.example.com
     User deploy
     IdentityFile ~/.ssh/id_ed25519_laptop_intel_web

   Host api-production
     HostName api.example.com
     User deploy
     IdentityFile ~/.ssh/id_ed25519_laptop_intel_api
         │
         ▼
6. PYTHON LAUNCHES KITTY WINDOWS
   kitty @ launch --title web-prod ssh web-production
   kitty @ launch --title api-prod ssh api-production
   kitty @ launch --title db-prod ssh db-production
   kitty @ launch --title local-control --cwd ~/ops
         │
         ▼
7. HYPRLAND TILES WINDOWS
   4 windows arranged in 2x2 grid
         │
         ▼
8. SSH CONNECTIONS ESTABLISHED
   3 windows SSH'd to remote servers
   1 window local (for Rust CLI control)
         │
         ▼
9. COMMANDS EXECUTE IN EACH WINDOW
   web-prod: htop
   api-prod: journalctl -u api.service -f
   db-prod: psql -U app production_db
   local-control: (ready for Rust CLIs)
         │
         ▼
10. USER RUNS RUST CLIs
    In local-control window:
    server-manager status --all
    log-aggregator follow --all
    terminal-session save monitoring-session
```

**Total time:** < 3 seconds (including SSH connections)

## Data Flow: Rust CLI Execution

```
1. USER RUNS COMMAND IN KITTY
   server-manager status --all
         │
         ▼
2. RUST BINARY EXECUTES
   /run/current-system/sw/bin/server-manager
         │
         ▼
3. READS CONFIGURATION
   ~/.config/server-manager/servers.toml

   [[servers]]
   name = "web-prod"
   host = "web-production"

   [[servers]]
   name = "api-prod"
   host = "api-production"

   [[servers]]
   name = "db-prod"
   host = "db-production"
         │
         ▼
4. READS SSH CONFIG
   ~/.ssh/config (auto-generated by agenix)

   Host web-production
     HostName web.example.com
     IdentityFile ~/.ssh/id_ed25519_laptop_intel_web
         │
         ▼
5. PARALLEL SSH CONNECTIONS (tokio async)
   ┌─────────────────┐
   │ SSH web-prod    │  ─┐
   │ Run: df -h,     │   │
   │      free -m,   │   │  All in parallel
   │      uptime     │   │  (< 2s total)
   └─────────────────┘   │
   ┌─────────────────┐   │
   │ SSH api-prod    │  ─┤
   │ Run: df -h,     │   │
   │      free -m,   │   │
   │      uptime     │   │
   └─────────────────┘   │
   ┌─────────────────┐   │
   │ SSH db-prod     │  ─┘
   │ Run: df -h,     │
   │      free -m,   │
   │      uptime     │
   └─────────────────┘
         │
         ▼
6. AGGREGATE RESULTS
   Merge health check results
         │
         ▼
7. FORMAT AS TABLE
   Using tabled crate

   Server      Status  CPU    Memory   Disk
   ──────────  ──────  ─────  ───────  ─────
   web-prod    OK      15%    2.1 GB   45%
   api-prod    OK      22%    4.5 GB   38%
   db-prod     OK      8%     12.3 GB  62%
         │
         ▼
8. DISPLAY IN TERMINAL
   Colourized output (green=OK, red=ERROR)
```

**Total time:** < 2 seconds for 3 servers

│  - Read DB connection strings from environment variables                    │

│  - No hardcoded credentials                                                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

## Component Dependencies

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              DEPENDENCY GRAPH                                │
└─────────────────────────────────────────────────────────────────────────────┘

NixOS System Configuration
    ├── modules/desktop/hyprland/default.nix
    │       ├── Hyprland package (from inputs.hyprland)
    │       ├── Waybar, Wofi, Dunst
    │       └── Hotkey bindings (config/hypr/keybinds.conf)
    │
    ├── modules/desktop/kitty/default.nix
    │       ├── Kitty package
    │       ├── Python3 + toml/pyyaml packages
    │       ├── Python kittens (config/kitty/kittens/)
    │       └── Kitty remote control enabled
    │
    ├── modules/core/ssh-config.nix
    │       ├── Agenix secrets (decrypted SSH keys)
    │       └── Auto-generated ~/.ssh/config
    │
    └── flake.nix (Rust packages)
            ├── terminal-session (Rust binary)
            │       └── Dependencies: clap, serde, toml, tokio
            │
            ├── server-manager (Rust binary)
            │       └── Dependencies: clap, tokio, ssh2, tabled, colored
            │
            ├── log-aggregator (Rust binary)
            │       └── Dependencies: clap, tokio, regex, chrono, colored
            │
            └── db-tools (Rust binary)
                    └── Dependencies: clap, tokio-postgres, tabled, serde_json

Runtime Dependencies:

Python Kittens
    ├── Kitty (must be running with remote control enabled)
    ├── ~/.config/kitty/sessions/*.toml (layout configs)
    ├── ~/.ssh/config (auto-generated by agenix)
    └── dunst (for error notifications)

Rust CLIs
    ├── ~/.config/server-manager/servers.toml (server definitions)
    ├── ~/.config/log-aggregator/sources.toml (log sources)
    ├── Environment variables (DB_PRODUCTION_URL, etc.)
    └── SSH config (for server connections)
```

## File Permissions & Security

```
Configuration Files:
~/.config/kitty/kitty.conf                  (644 - world-readable)
~/.config/kitty/sessions/*.toml             (644 - world-readable)
~/.config/server-manager/servers.toml       (644 - world-readable)
~/.local/share/kitty/autosave.json          (600 - user-only)

SSH Keys (decrypted by agenix):
/run/agenix/github-ssh-personal-laptop-intel  (400 - read-only)
/run/agenix/server-ssh-web-laptop-intel       (400 - read-only)
~/.ssh/id_ed25519_laptop_intel_web            (symlink to /run/agenix/...)

Database Credentials:
/run/agenix/db-production-connection        (400 - read-only)
Environment: $DB_PRODUCTION_URL             (exported on shell init)

Rust Binaries:
/run/current-system/sw/bin/terminal-session  (755 - world-executable)
/run/current-system/sw/bin/server-manager    (755 - world-executable)
/run/current-system/sw/bin/log-aggregator    (755 - world-executable)
/run/current-system/sw/bin/db-tools          (755 - world-executable)

Python Scripts:
~/.config/kitty/kittens/*.py                (755 - world-executable)
~/.local/bin/kitty-session                  (755 - world-executable)
```
