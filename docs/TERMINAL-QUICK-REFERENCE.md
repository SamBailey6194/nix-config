## Hotkeys

| Hotkey | Action |
|--------|--------|
| `Super+Return` | Single Kitty terminal |
| `Super+Shift+1` | Development layout (4 terminals) |
| `Super+Shift+2` | Monitoring layout (3 SSH + 1 local) |
| `Super+Shift+3` | Deployment layout |
| `Super+Shift+4-9` | Custom layouts |

## Rust CLI Commands

### terminal-session

```bash
terminal-session list                 # Show active sessions
terminal-session save my-work         # Save current state
terminal-session restore my-work      # Restore saved state
terminal-session kill --all           # Close all windows
```

### server-manager

```bash
server-manager status --all           # Check all servers (< 2s)
server-manager status --server web    # Check specific server
server-manager deploy --env staging   # Deploy to staging
server-manager rollback --env staging # Rollback deployment
```

### log-aggregator

```bash
log-aggregator fetch --service api --since 1h
log-aggregator follow --all
log-aggregator fetch --level ERROR --since 24h
log-aggregator export --format json --output logs.json
```

### db-tools

```bash
db-tools query --sql "SELECT COUNT(*) FROM users" --env production
db-tools replicas --env production
db-tools admin --vacuum --env staging
db-tools admin --slow-queries --env production
```

## Creating Custom Layouts

**Location:** `~/.config/kitty/sessions/my-layout.toml`

```toml
[layout]
name = "my-layout"
description = "Custom workflow"

[[windows]]
title = "local-dev"
directory = "~/Projects/current"
command = ""

[[windows]]
title = "ssh-server"
ssh_target = "my-server"  # From ~/.ssh/config
command = "htop"

[[windows]]
title = "logs"
directory = "~/Projects/current"
command = "tail -f logs/app.log"

[[windows]]
title = "control"
directory = "~/ops"
command = ""
```

**Launch:** `Super+Shift+4` (after mapping in keybinds.conf)

## SSH Configuration

**Auto-generated by agenix:** `~/.ssh/config`

```
Host my-server
  HostName server.example.com
  User deploy
  IdentityFile ~/.ssh/id_ed25519_laptop_intel_my_server
```

**Add new server:**
```bash
just add-server my-server
# Follow prompts to generate per-device SSH key
```

## Troubleshooting

### Kitty won't launch
```bash
# Check Hyprland logs
journalctl --user -u hyprland.service | grep kitty

# Test Kitty directly
kitty --single-instance --detach
```

### SSH connection fails
```bash
# Check SSH config
cat ~/.ssh/config | grep -A5 "my-server"

# Test SSH manually
ssh -v my-server

# Check error log
tail ~/.local/share/kitty/session-errors.log
```

### Layout not found
```bash
# List available layouts
ls ~/.config/kitty/sessions/

# Validate layout syntax
python3 -c "import toml; toml.load('~/.config/kitty/sessions/my-layout.toml')"
```

### Rust CLI not found
```bash
# Check if installed
which terminal-session

# Rebuild system
just rebuild

# Enter dev shell
nix develop
```

## Key Files

```
~/.config/kitty/
├── kitty.conf                    # Kitty configuration
├── ayu-dark.conf                 # Colour scheme
├── kittens/
│   ├── session-launcher.py       # Main session orchestrator
│   ├── ssh-manager.py            # SSH connection builder
│   └── layout-parser.py          # TOML layout parser
└── sessions/
    ├── development.toml          # Local dev layout
    ├── monitoring.toml           # SSH monitoring layout
    └── deployment.toml           # Deployment layout

~/.ssh/
├── config                        # Auto-generated by agenix
└── id_ed25519_laptop_intel_*     # Per-device SSH keys (symlinks to /run/agenix/)

~/.config/server-manager/
├── servers.toml                  # Server definitions
└── deploy.toml                   # Deployment configs

~/.config/log-aggregator/
└── sources.toml                  # Log sources

~/.local/share/kitty/
├── autosave.json                 # Auto-saved session state
└── session-errors.log            # Error log
```
