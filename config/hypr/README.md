Modular Hyprland configuration with base settings and device-specific overrides.

## Structure

```
config/hypr/
├── hyprland.conf           # Main config (sources all other files)
├── base.conf               # Core settings (modifier, layout, misc)
├── monitors.conf           # Monitor configuration
├── input.conf              # Keyboard, mouse, touchpad
├── appearance.conf         # Decorations, blur, shadows
├── animations.conf         # Animation settings
├── keybinds.conf           # Keybindings
├── windowrules.conf        # Window rules
├── autostart.conf          # Startup applications
└── devices/                # Device-specific overrides
    ├── laptop-intel.conf   # Intel laptop (i5-10210U, 32GB)
    ├── framework.conf      # Framework AMD (Ryzen + Radeon, 64GB)
    └── devtower.conf       # AMD desktop (CPU + GPU, 64GB, Go XLR)
```

## Usage

### With Home Manager (Recommended)

The Home Manager configuration in `home/modules/hyprland.nix` will automatically:
1. Enable Hyprland
2. Configure all settings programmatically
3. Apply device-specific overrides from `home/{laptop,framework,devtower}.nix`

After rebuilding with Home Manager, your Hyprland config will be at:
- `~/.config/hypr/hyprland.conf` (generated by Home Manager)

### Manual Usage (Standalone)

If you want to use these config files directly without Home Manager:

1. **Symlink the base configuration:**
   ```bash
   ln -sf ~/nix-config/config/hypr/hyprland.conf ~/.config/hypr/hyprland.conf
   ln -sf ~/nix-config/config/hypr/*.conf ~/.config/hypr/
   ln -sf ~/nix-config/config/hypr/devices ~/.config/hypr/devices
   ```

2. **Enable device-specific config:**
   Edit `hyprland.conf` and uncomment the appropriate device line:
   ```conf
   # For laptop-intel:
   source = ~/.config/hypr/devices/laptop-intel.conf

   # For framework:
   source = ~/.config/hypr/devices/framework.conf

   # For devtower:
   source = ~/.config/hypr/devices/devtower.conf
   ```

3. **Reload Hyprland:**
   ```bash
   hyprctl reload
   ```

## Customization

### Base Configuration

All shared settings are in the modular files:
- **base.conf**: Modifier key, layout, core settings
- **monitors.conf**: Default monitor setup
- **input.conf**: Keyboard layout, mouse, touchpad
- **appearance.conf**: Gaps, borders, blur, shadows, opacity
- **animations.conf**: Animation curves and speeds
- **keybinds.conf**: All keyboard shortcuts
- **windowrules.conf**: Floating, opacity, workspace rules
- **autostart.conf**: Applications to start automatically

### Device-Specific Overrides

Each device can override any setting:
- **laptop-intel.conf**: Battery-optimized settings, single monitor
- **framework.conf**: High-DPI scaling, creative workflow
- **devtower.conf**: Multi-monitor, desktop performance, Go XLR

## Key Features

### Vim-Style Navigation
- `Super+H/J/K/L`: Move focus between windows
- `Super+Shift+H/J/K/L`: Move windows

### Workspaces
- `Super+1-0`: Switch to workspace 1-10
- `Super+Shift+1-0`: Move window to workspace 1-10
- `Super+S`: Toggle scratchpad (special workspace)

### Applications
- `Super+Return`: Terminal (kitty)
- `Super+D`: App launcher (wofi)
- `Super+B`: Browser (LibreWolf)
- `Super+Shift+B`: Firefox
- `Super+E`: File manager (Thunar)

### Window Management
- `Super+Q`: Close window
- `Super+V`: Toggle floating
- `Super+M`: Fullscreen
- `Super+J`: Toggle split (dwindle)

### Screenshots
- `Print`: Screenshot region (with slurp + swappy)
- `Super+Print`: Screenshot full screen (with swappy)

### Laptop Controls
- `XF86AudioRaiseVolume/LowerVolume`: Volume control
- `XF86AudioMute`: Mute audio
- `XF86MonBrightnessUp/Down`: Brightness control

## Integration with Home Manager

The NixOS configuration (`home/modules/hyprland.nix`) provides:
- Declarative Hyprland configuration
- Waybar (status bar)
- Wofi (app launcher)
- Hyprpaper (wallpaper daemon)
- Hypridle (idle management)
- Hyprlock (screen locker)
- Dunst (notifications)

Device-specific settings are in:
- `home/laptop.nix` (laptop-intel)
- `home/framework.nix` (framework)
- `home/devtower.nix` (devtower)

## Ayu Dark Theme

The configuration uses Ayu Dark color scheme:
- **Active border**: Orange (#ffb454) → Blue (#59c2ff) gradient
- **Inactive border**: Gray (#595959)
- **Background**: Dark (#0f1419)
- **Accent colors**: Throughout Waybar and Wofi

## Tips

1. **Test changes without restarting:**
   ```bash
   hyprctl reload
   ```

2. **View current config:**
   ```bash
   hyprctl reload -c
   ```

3. **Monitor info:**
   ```bash
   hyprctl monitors
   ```

4. **Window info:**
   ```bash
   hyprctl clients
   ```

5. **Debug issues:**
   ```bash
   journalctl --user -u hyprland.service
   ```
